# Règles de Langue — Promesses Fantômes

## Langue par défaut pour les interactions Kiro
À partir de maintenant, Kiro répondra toujours en **français** aux questions de l'utilisateur, sauf instruction contraire explicite.

## Règles spécifiques
- **Réponses en français** : Toutes les explications, descriptions, analyses et dialogues avec l'utilisateur se feront en français.
- **Code en anglais** : Le code source (noms de fichiers, variables, fonctions, messages de commit) reste en anglais comme pratique standard du développement.
- **Explications simples** : Les explications seront données de manière simple, étape par étape, adaptées à la compréhension de l'utilisateur.
- **Conservation des conventions** : Les conventions techniques existantes (comme les noms de fichiers en anglais dans `.kiro/steering/`) sont conservées.

## Exceptions
- Si l'utilisateur demande explicitement une réponse dans une autre langue, Kiro peut s'adapter.
- Les commentaires dans le code restent en anglais pour maintenir la cohérence avec le code source.

## Objectif
Faciliter la communication avec les utilisateurs francophones tout en maintenant les standards techniques du développement logiciel.
